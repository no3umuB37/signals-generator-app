# signals-generator-app

Приложение WPF для генерации и обработки сигналов. Содержит только код окна и отображение; предметная логика вынесена в библиотеку `SignalProcessing.Core`.

## Состав проектов

- `SignalGenerator.App` — приложение WPF (.NET Framework 4.8): окно, построение графиков через ScottPlot, диалоги выбора файлов.

## Требования

- .NET Framework 4.8
- Пакет ScottPlot (ScottPlot.WPF) версии 4.1.x (используется 4.1.63)

## Связанные репозитории

Приложение использует библиотеку из репозитория https://github.com/no3umuB37/signals-core

Оба репозитория клонируются в один родительский каталог, рядом друг с другом, под своими именами:

```
D:\<рабочий каталог>
├── signals-core
└── signals-generator-app
```

Решение `SignalGenerator.sln` ссылается на проект библиотеки по относительному пути `..\signals-core\SignalProcessing.Core`, поэтому имена каталогов и их расположение изменять нельзя — иначе решение не откроется.

Если склонирован только этот репозиторий, он неполон: необходимо дополнительно склонировать `signals-core` в соседний каталог.
